# AcousticSpace

Deepfake audio detection via Room Impulse Response (RIR) analysis.

## Problem
Standard deepfake audio detectors focus on vocal artifacts. AcousticSpace instead checks whether the background acoustic reflection (RIR) of an audio clip is physically consistent with a real recording environment.

## Stack
- Backend: Python, Librosa, PyTorch, HuggingFace (Audio Spectrogram Transformer), FastAPI
- Frontend: React, TypeScript, Wavesurfer.js
